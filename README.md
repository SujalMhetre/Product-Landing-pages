# 🌐 Landing Pages Showcase

A personal collection of high-quality landing page clones built using **HTML, CSS, and JavaScript**.  
Each page is recreated from real-world brand websites to sharpen my layout, responsiveness, and design eye.

---

## 🚀 Projects Included

### 1. 🛒 Amazon Landing Page Clone
A faithful recreation of Amazon's homepage focusing on multi-section structure and product browsing layout.

- **Focus:** Multi-section layout, navbar, product cards, responsive grid
- **Tech:** HTML5, CSS3 (Flexbox + Media Queries)

🔗 **Live Demo:** [View on GitHub Pages](https://sujalmhetre.github.io/Amazon-Inspired-Landing-Page/)

---

### 2. 🍎 Apple Landing Page Clone
A clean, minimal recreation of Apple's product landing page, emphasizing whitespace and visual hierarchy.

- **Focus:** Elegant layout, whitespace usage, section-based design, smooth transitions
- **Tech:** HTML5, CSS3 (Grid + Transitions)

🔗 **Live Demo:** [View on GitHub Pages](https://sujalmhetre.github.io/Apple-Inspired-Landing-Page/)

---

### 3. 📖 Magazine Landing Page
An interactive magazine experience where each scroll smoothly transitions to the next issue, simulating a real publication flip.

- **Focus:** Smooth-scroll navigation, color-changing sections, scroll-driven layout
- **Tech:** HTML5, CSS3 (Flexbox + Positioning), JavaScript

🔗 **Live Demo:** [View on GitHub Pages](https://sujalmhetre.github.io/Magazine-Landing-Page/)

## 📂 How to Run Locally

No build tools or dependencies required — just open and go.

```bash
git clone https://github.com/SujalMhetre/Product-Landing-pages.git
cd Product-Landing-Pages
```

Then open any project folder and double-click `index.html`, or use Live Server in VS Code.
